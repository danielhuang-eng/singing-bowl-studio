# 缽間：頌缽聆聽工作室

由上班鼓勵器複製後獨立製作。原版檔案與原 GitHub 專案不變。全繁體中文，左側聲音調校／今日累積，右側敲缽互動。

「開啟網站時自動敲缽」預設開啟並獨立儲存；不受上下班時間、假日或薪資計算狀態限制。瀏覽器允許自動音訊時開頁即播放，若遭阻擋則顯示點擊啟用提示。關閉設定則停止並改為手動開始。開始後每秒敲擊一次，槌子與波紋對應音訊時鐘。可手動敲擊、暫停、靜音。使用 AudioWorklet 音訊執行緒每秒敲擊；切換分頁或最小化視窗持續播放，返回時不補敲。裝置休眠、頁面關閉或系統凍結音訊仍會中斷；中斷後可點選開始繼續。瀏覽器必須先獲得一次點擊才能發聲。

## 音色研究與預設

來源：Terwagne & Bush (2011), Tibetan singing bowls, Nonlinearity 24 R51–R66，https://doi.org/10.1088/0951-7715/24/8/R01 。全文：https://thales.mit.edu/bush/wp-content/uploads/2012/04/TibetanBowls.pdf

尺寸、壁厚、材料的彈性與密度影響共振頻率；槌頭與敲擊方式影響振動模態激發；不對稱形成近頻分裂與拍頻。依論文式 (5) 的空缽 m=0 模態模型，取 n=2…7 的相對頻率約 1、2.8284、5.4233、8.7706、12.8663、17.7088，以雙振盪器及獨立衰減合成。

預設「溫潤古缽」基頻 187 Hz 參考論文表一 Tibet 2；其餘參數為設計者調校：餘韻10秒、拍頻1.2Hz、亮度30%、槌頭硬度22%、力道50%、殘響24%、音量45%。不存在可引用的統一「大師級參數」，不宣稱此為大師錄音或認證音色。

控制項：基頻、餘韻長度、泛音明亮度、槌頭硬度、拍頻、敲擊力道、空間殘響、音量。音色參數於新敲擊生效，殘響／音量即時影響輸出。支援三組預設、自訂設定儲存、減少動態效果偏好與手機版面。

每秒一次的節奏會使長尾韻疊加。採用振幅正規化與動態壓縮；實際音量仍依設備設定而異。沒有療效宣稱。主視覺由圖片生成模型製作，槌子與波紋為程式動畫。
